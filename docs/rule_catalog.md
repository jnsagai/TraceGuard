# Rule Catalog

- R-ATOM-001: Parent atom coverage required.
- R-CONSTRAINT-001: Numeric child constraint must be compatible with parent constraint.
- R-CONSTRAINT-002: Linked child must provide comparable numeric evidence when the parent atom has a numeric constraint.
- R-SAFETY-001: Safety integrity coverage requires child evidence or reviewable rationale.
- R-VERIF-001: Vague wording is unverifiable and must be reviewed.
- R-TERM-002: Ambiguous glossary aliases are invalid.
